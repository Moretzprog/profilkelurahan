WEBSISE PROFILE KELURAHAN

Website Profil Kelurahan Sarijaya adalah aplikasi berbasis web yang menampilkan berbagai informasi mengenai potensi, kelembagaan, dan kegiatan yang ada di Kelurahan Sarijaya.
Dibuat dengan tujuan untuk mempermudah masyarakat dalam mengakses informasi kelurahan secara digital.

🚀 Fitur Utama

🏠 Beranda: Menampilkan sekilas profil Kelurahan Sarijaya.

🧾 Profil: Berisi visi, misi, sejarah, dan struktur organisasi kelurahan.

🖼️ Galeri: Menampilkan album dan sub-album kegiatan kelurahan.

🏢 Lembaga: Menampilkan data kelembagaan masyarakat, ekonomi, dan pendidikan.

📞 Kontak: Informasi kontak dan alamat kantor kelurahan.

🔐 Admin Panel: Login untuk admin agar dapat menambah, mengedit, dan menghapus data.
